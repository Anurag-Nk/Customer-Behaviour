# Customer-Behaviour

# 🛍️ Customer Behavior Analysis

An end-to-end **Customer Behavior Analysis project** built using **Python, Pandas, SQL, PostgreSQL, and Power BI** to analyze customer purchasing patterns, subscription behavior, product performance, revenue distribution, demographics, and shipping preferences.

---

## 📖 Short Description / Purpose

The **Customer Behavior Analysis** project analyzes customer shopping data through a complete data analytics workflow — from **data exploration and cleaning in Python to SQL-based analysis in PostgreSQL and interactive visualization in Power BI**.

The project transforms raw customer transaction data into meaningful business insights that can help organizations understand customer behavior, identify high-performing product categories, analyze valuable customer segments, and improve business decision-making.

---

# 🛠️ Tech Stack

The project was developed using:

- 🐍 **Python** – Data analysis and preprocessing.
- 📓 **Jupyter Notebook** – Exploratory Data Analysis (EDA) and data preparation.
- 🐼 **Pandas** – Data cleaning, transformation, and analysis.
- 🗄️ **PostgreSQL** – Database storage and SQL-based analysis.
- 🔤 **SQL** – Querying, aggregations, filtering, grouping, and business analysis.
- 📊 **Power BI** – Interactive dashboard development and visualization.
- 🎨 **Dashboard UI Design** – Custom dark-themed dashboard with orange and gold accents.

---

# 📂 Dataset

The project uses a **Customer Shopping / Customer Behavior Dataset** containing customer-level purchasing information.

The dataset includes information related to:

- Customer ID
- Age
- Gender
- Category
- Purchase Amount
- Subscription Status
- Review Rating
- Shipping Type
- Product Information
- Customer purchasing behavior

---
# 🎯 Business Problem

Businesses generate large amounts of customer shopping data, but analyzing raw records makes it difficult to quickly answer important business questions.

This project focuses on answering questions such as:

- How many customers are present in the dataset?
- What is the average customer purchase amount?
- What is the average review rating?
- What percentage of customers are subscribed?
- Which product categories generate the highest sales?
- Which product categories generate the highest revenue?
- Which age groups generate the most revenue?
- Which age groups have the highest sales volume?
- How does customer behavior differ by gender?
- Which shipping methods are preferred by customers?
- Which customer segments should the business focus on?
- What insights can be used to improve customer engagement and revenue?

---
# 🎯 Project Objectives

The main objectives of this project are to:

- Clean and prepare raw customer shopping data.
- Perform exploratory data analysis using Python and Pandas.
- Store and manage structured data using PostgreSQL.
- Perform business analysis using SQL.
- Identify customer purchasing patterns.
- Analyze product category performance.
- Analyze customer subscription behavior.
- Compare sales and revenue across age groups.
- Understand customer demographics.
- Analyze customer satisfaction using review ratings.
- Analyze customer shipping preferences.
- Build an interactive Power BI dashboard.
- Convert analytical findings into actionable business insights.
